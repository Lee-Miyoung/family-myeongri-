계산 기준 안내

한국형 3중 검증을 사용합니다. ① KASI 정본 음력·정밀 절기표를 내장한 manseryeok 2.0을 기준 엔진으로 두고, ② lunar-javascript, ③ @fullstackfamily/manseryeok 결과를 서로 비교합니다. 세 엔진의 연·월·일·시주가 같으면 “3중 일치”로 표시하고, 다르면 해당 사주에 경계/기준 확인 경고를 냅니다.

왜 KASI API를 브라우저에서 직접 부르지 않나요?

공공데이터 API 인증키를 index.html에 넣으면 누구나 키를 볼 수 있어 보안상 좋지 않습니다. 현재 기준 엔진은 KASI 정본 음력과 KASI와 분 단위로 맞춘 절기 데이터를 내장한 라이브러리를 사용합니다. 정식 가족 서비스에서는 서버에서 KASI API를 추가 대조할 수 있도록 확장합니다.

한국 출생시간 관련 주의

23시 전후의 자시 처리, 진태양시 보정, 과거 한국 표준시처럼 학파·기준에 따라 달라질 수 있는 항목은 자동으로 “기준 확인 필요”로 표시합니다. 날짜탐색의 계산 기준에서 자시 관법과 경도 보정을 선택할 수 있습니다. 과거 표준시·서머타임 복원은 별도 확인이 필요합니다.
